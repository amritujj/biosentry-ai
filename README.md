## ? Features
- **Educational Reference Chat**: Query resolution for classical herbs, botanical names, and plant parts with authentic citations.
- **Guided Symptom Triage Flow**: Multi-step triage flow for headache severity, onset, duration, and emergency red-flag safety warnings.
- **Source Library & Drawer**: Inspect evidence excerpts and sources directly from health reference authorities.
- **Autonomous Client-Side Storage**: Seamless guest mode saving conversations and preferences locally in the browser.
- **Lightweight Procedural Art**: Dynamic botanical graphics rendered via HTML5 `<canvas>`.
